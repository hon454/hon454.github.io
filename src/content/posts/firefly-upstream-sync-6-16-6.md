[Firefly](https://github.com/CuteLeaf/Firefly) 6.16.3 이후부터 6.16.6과 그 이후의 `0f2fab602`까지 업스트림 변경을 반영했다.

## 화면과 탐색

- 내비게이션을 `dynamic` 모드로 변경했다. 아래로 스크롤하면 숨고 위로 스크롤하면 다시 나타난다.
- 배너·전체 화면 배경의 내비게이션 투명 모드를 새 설정 구조에 맞췄다.
- 모바일 내비게이션 패널이 화면 전체를 덮도록 구조를 수정하고, 밝은·어두운 테마 전환 버튼의 동작과 표시를 정리했다.

## 시리즈

- `series`와 `seriesOrder`로 여러 글을 묶는 기능을 추가했다.
- 시리즈를 지정한 글에 같은 시리즈의 글 목록을 표시하며, `/series/`에서 전체 시리즈를 제공한다.
- 설정 방법을 [Firefly 블로그 가이드](/posts/firefly-blog-guide/)에 추가했다.

## 미디어 목록

- Bangumi, VNDB, MyAnimeList의 NSFW 처리를 공통 설정으로 통합했다.
- 현재 Bangumi와 MyAnimeList의 해당 항목은 숨기고, VNDB 표지는 흐리게 표시한다.

## OG 이미지와 구조화 데이터

- OG 이미지 생성 구현을 Satori에서 Takumi로 교체했다. 이 블로그의 자동 생성 기능은 비활성화 상태다.
- 글과 프로필의 구조화 데이터를 추가했다.
- 게시자 로고, 프로필 이미지와 글 표지가 실제 배포 주소를 사용하도록 이미지 경로 처리를 수정했다.

## 카테고리 가로 스크롤

- 카테고리 바를 더 움직일 수 있을 때만 세로 휠 입력을 가로 스크롤로 변환한다. 양 끝에서는 세로 페이지 스크롤이 이어지도록 수정했다.
- 트랙패드 가로 입력과 `Ctrl` 확대·축소 입력은 가로채지 않는다.
- 부드러운 스크롤을 제거해 휠 입력에 즉시 반응하도록 변경했다.

## 전체 화면 배경

- `classic`과 `hero` 레이아웃을 추가했다. `classic`은 배경을 문서 흐름 안에 배치하고, `hero`는 첫 화면 배경을 고정한다. 현재는 업스트림 기본값인 `classic`을 사용한다.
- 물결 효과와 그라데이션을 배너·전체 화면 배경의 공통 설정으로 옮겼다.
- 표시 설정을 활성화하면 두 전체 화면 레이아웃을 전환할 수 있다.

## 카테고리 접근성

- 카테고리가 없는 글의 링크 설명에 현재 언어의 ‘미분류’ 문구를 사용하도록 수정했다.
