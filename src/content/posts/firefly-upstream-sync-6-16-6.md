[Firefly](https://github.com/CuteLeaf/Firefly) 업스트림 기준을 6.16.3에서 6.16.6과 그 이후의 `0f2fab602`까지 올렸다. 내비게이션 동작, 시리즈, 미디어 목록 필터링, OG 이미지와 구조화 데이터 처리를 반영한 뒤 카테고리 바와 전체 화면 배경 변경도 추가했다. 기존 글과 Steady Spiral 설정은 그대로 유지했다.

## 화면과 탐색

내비게이션은 `dynamic` 모드로 변경했다. 아래로 스크롤하면 숨고 위로 스크롤하면 다시 나타난다. 배너와 전체 화면 배경에서 사용하는 투명 모드도 새 설정 구조에 맞췄다.

모바일 내비게이션 패널은 화면 전체를 안정적으로 덮도록 구조가 바뀌었다. 밝은 테마와 어두운 테마를 전환하는 버튼의 동작과 표시도 함께 정리됐다.

## 시리즈

여러 글을 `series`와 `seriesOrder`로 묶을 수 있게 됐다. 시리즈를 지정한 글에는 같은 묶음의 글 목록이 표시되고, `/series/`에서는 전체 시리즈를 모아 볼 수 있다.

설정 방법은 [Firefly 블로그 가이드](/posts/firefly-blog-guide/)에도 정리했다.

## 미디어 목록

Bangumi, VNDB, MyAnimeList의 NSFW 처리가 공통 설정을 사용하도록 바뀌었다. 현재 설정에서는 Bangumi와 MyAnimeList의 해당 항목을 숨기고, VNDB 표지는 흐리게 표시한다.

## OG 이미지와 구조화 데이터

OG 이미지 생성은 Satori 대신 Takumi를 사용한다. 이 블로그에서는 자동 생성을 계속 꺼 두었지만, 나중에 기능을 켤 때는 새 구현을 사용하게 된다.

글과 프로필에 들어가는 구조화 데이터도 추가됐다. 게시자 로고, 프로필 이미지와 글 표지가 실제 배포 주소를 사용하도록 이미지 경로 처리도 함께 반영했다.

## 카테고리 가로 스크롤

카테고리가 화면 너비를 넘으면 마우스 휠의 세로 입력을 가로 스크롤로 바꾼다. 기존에는 스크롤 영역의 처음이나 끝에서도 휠 이벤트를 계속 잡아 페이지 스크롤이 막힐 수 있었다.

수정된 동작은 카테고리 바를 더 움직일 수 있을 때만 휠 입력을 가로 방향으로 사용한다. 처음이나 끝에 도달하면 이벤트를 브라우저에 넘겨 페이지가 다시 세로로 움직인다. 트랙패드의 가로 입력과 `Ctrl`을 누른 확대·축소 입력도 별도로 가로채지 않는다. 부드러운 스크롤 설정은 제거해 휠 입력에 바로 반응하도록 바뀌었다.

## 전체 화면 배경

전체 화면 배경에 `classic`과 `hero` 레이아웃이 추가됐다. `classic`은 배경을 문서 흐름 안에 배치하고, `hero`는 기존처럼 첫 화면 배경을 고정한다. 이 블로그는 새 업스트림 기본값인 `classic`을 사용한다.

물결 효과와 그라데이션 설정은 배너 전용 영역에서 공통 설정으로 이동했다. 배너와 전체 화면 배경이 같은 값을 사용하며, 표시 설정을 활성화한 경우 두 전체 화면 레이아웃을 전환할 수도 있다.

## 카테고리 접근성

카테고리가 없는 글의 링크 설명도 보완됐다. 카테고리 이름이 비어 있을 때는 빈 값 대신 현재 언어의 ‘미분류’ 문구를 사용한다.

## 기존 설정

프로필과 사이트 제목, 로고, favicon, 개인 배경 이미지와 문구, 링크를 포함한 Steady Spiral 설정은 유지했다. 기존 글과 동적 콘텐츠도 손대지 않았다. 이전에 삭제한 Firefly 예제 글은 다시 추가하지 않았다.

6.16.6 반영 기준은 [`f7c93c932`](https://github.com/CuteLeaf/Firefly/commit/f7c93c932c3241239f6f0d330e0b5c1bc701ce45), 이후 변경을 포함한 최종 기준은 [`0f2fab602`](https://github.com/CuteLeaf/Firefly/commit/0f2fab602407eb577cdcca066049fe947563ae0f) 커밋이다.
