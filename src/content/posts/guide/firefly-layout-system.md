## 📖 개요

Firefly는 콘텐츠 요구와 취향에 따라 블로그의 시각적 구성을 조정할 수 있는 유연한 레이아웃 시스템을 제공합니다. 레이아웃은 주로 **사이드바 레이아웃**과 **글 목록 레이아웃**으로 이루어지며, 두 요소가 함께 페이지 전체 구조를 결정합니다.

이 글에서는 Firefly의 여러 레이아웃 모드와 특징, 활용 상황, 조합별 결과를 자세히 소개합니다.

## 1. 사이드바 레이아웃 시스템

사이드바는 내비게이션, 카테고리, 태그, 통계 같은 보조 콘텐츠를 보여 주는 블로그의 중요한 요소입니다. Firefly는 두 가지 사이드바 레이아웃 모드를 지원합니다.

### 1.1 단일 사이드바 모드

#### 왼쪽 사이드바 (position: "left")

![왼쪽 사이드바 레이아웃](../images/left-list.avif)

#### 오른쪽 사이드바 (position: "right")

![오른쪽 사이드바 레이아웃](../images/right-grid2.avif)

#### 특징

- 사이드바가 페이지 한쪽에 고정됩니다.
- 글 읽기 영역이 더 넓고 쾌적합니다.
- 덜 빽빽하고 간결한 구성을 제공합니다.

#### 적합한 상황

- 전통적인 블로그 스타일
- 내비게이션과 카테고리를 강조하는 블로그
- 프로필을 돋보이게 할 개인 블로그
- 콘텐츠가 중심이고 보조 정보의 비중이 낮은 경우

:::tip
`showBothSidebarsOnPostPage`로 글 상세 페이지에 양쪽 사이드바를 표시할지 설정할 수 있습니다.

position이 left 또는 right일 때 이 옵션을 켜면 글 상세 페이지에는 양쪽 사이드바를, 홈 같은 다른 페이지에는 단일 사이드바를 표시합니다.

평소에는 단일 사이드바를 쓰되 글 상세 페이지에서 반대편 사이드바의 목차 같은 컴포넌트가 필요할 때 유용합니다.
:::


#### 설정 예시

```typescript
// src/config/sidebarConfig.ts
export const sidebarLayoutConfig: SidebarLayoutConfig = {
  enable: true,
  position: "left", // 왼쪽 사이드바
  showBothSidebarsOnPostPage: true, // 글 상세 페이지에 양쪽 사이드바 표시 여부
};
```

---

### 1.2 양쪽 사이드바 모드 (position: "both")

#### 특징

- 왼쪽과 오른쪽에 사이드바가 모두 있습니다.
- 주 콘텐츠 영역이 가운데에 있습니다.
- 화면 공간을 최대한 활용합니다.
- 더 많은 보조 정보를 보여 줄 수 있습니다.
- 와이드 모니터에 적합합니다.

#### 레이아웃 구조

![양쪽 사이드바와 목록 레이아웃](../images/both-list.avif)

![양쪽 사이드바와 그리드 레이아웃](../images/both-grid.avif)
#### 적합한 상황

- 와이드 화면 데스크톱 탐색
- 정보 밀도가 높은 블로그
- 많은 보조 콘텐츠를 보여 줘야 하는 경우
- 전문적인 기술 블로그


#### 설정 예시

```typescript
// src/config/sidebarConfig.ts
export const sidebarLayoutConfig: SidebarLayoutConfig = {
  enable: true,
  position: "both", // 양쪽 사이드바
```

## 2. 글 목록 레이아웃 시스템

글 목록은 블로그 홈과 아카이브 페이지의 핵심 콘텐츠입니다. Firefly는 두 가지 표시 방식과 여러 그리드 설정을 제공합니다.

### 2.1 목록 모드 (defaultMode: "list")

#### 특징

- 한 열로 세로 배치합니다.
- 글 표지 이미지를 왼쪽이나 오른쪽에 표시할 수 있습니다.
- 더 많은 글 요약을 보여 줍니다.
- 깊이 있는 읽기에 적합합니다.

#### 목록 레이아웃 구조

![목록 모드 레이아웃](../images/left-list.avif)

#### 표지 위치

목록 모드의 표지 이미지는 기본적으로 카드 오른쪽에 있으며 `coverPosition`으로 왼쪽으로 옮길 수 있습니다. 왼쪽으로 옮기면 카드 왼쪽 가장자리에 붙도록 설계된 제목 앞 테마색 세로선이 자동으로 숨겨지고 여백은 본문에 사용됩니다.

그리드 모드의 표지는 카드 위쪽에 고정되어 이 설정의 영향을 받지 않습니다.

#### 장점

- ✅ 표지 이미지가 눈길을 끌어 시각적 효과가 큽니다.
- ✅ 요약과 태그 등 더 많은 글 정보를 보여 줄 수 있습니다.
- ✅ 이미지 콘텐츠가 풍부한 블로그에 적합합니다.
- ✅ 모바일 친화적이며 한 열이라 읽기 쉽습니다.
- ✅ 단일·양쪽 사이드바 설정 모두와 호환됩니다.

#### 설정 예시

```typescript
// src/config/siteConfig.ts
export const siteConfig: SiteConfig = {
  postListLayout: {
    defaultMode: "list",    // 목록 모드
    coverPosition: "right", // 표지 위치: "right" 오른쪽, "left" 왼쪽
  },
};
```

---

### 2.2 그리드 모드 (defaultMode: "grid")

#### 특징

- 브라우저 너비에 맞춰 열 수를 자동 조정합니다.
- 구성이 촘촘하고 정보 밀도가 높습니다.
- 빠르게 훑어보기에 적합합니다.

#### 반응형 그리드

그리드 모드는 `columnWidth`로 카드의 최소 너비(px)를 설정하며 브라우저가 컨테이너의 사용 가능한 너비에 따라 열 수를 자동 계산합니다.

![그리드 레이아웃](../images/left-grid3.avif)

#### 설정 예시

```typescript
// src/config/siteConfig.ts
export const siteConfig: SiteConfig = {
  postListLayout: {
    defaultMode: "grid",
    grid: {
      masonry: true,      // 메이슨리 사용
      columnWidth: 320,   // 카드 최소 너비(px), 브라우저가 열 수 자동 계산
    },
  },
};
```

---

### 2.3 메이슨리 레이아웃 (Masonry)

Firefly의 그리드 모드는 지능형 메이슨리 레이아웃을 지원해 이미지와 텍스트가 섞인 글의 카드 높이가 달라 생기는 빈 공간 문제를 해결합니다.

![메이슨리 레이아웃](../images/masonry.avif)

- **지능형 배치**: 카드를 가장 짧은 열에 자동 배치해 세로 공간을 최대한 활용합니다.
- **빈 공간 제거**: 절대 위치로 각 카드 위치를 정확히 계산해 위 카드에 밀착시키고 세로 빈틈을 없앱니다.
- **반응형 열 수**: `columnWidth`와 컨테이너 너비에 따라 열 수를 동적으로 계산하므로 고정 설정이 필요하지 않습니다.
- **유연한 설정**: `siteConfig.ts`의 `postListLayout.grid.masonry` 옵션으로 기능을 자유롭게 켜고 끌 수 있습니다.

## 3. 레이아웃 조합 가이드

Firefly에서는 사이드바와 글 목록 레이아웃을 자유롭게 조합할 수 있습니다. 아래는 조합별 효과입니다.

| 사이드바 모드 | 글 목록 모드 | 추천도 | 적합한 상황 |
|-----------|------------|--------|---------|
| 단일 사이드바 | 목록 모드 | ⭐⭐⭐⭐⭐ | 사진·디자인·일상 블로그, 이미지와 몰입감 강조 |
| 단일 사이드바 | 그리드 모드 | ⭐⭐⭐⭐⭐ | 기술·노트 블로그, 읽기와 탐색 효율의 균형 |
| 양쪽 사이드바 | 목록 모드 | ⭐⭐⭐⭐⭐ | 많은 사이드바 정보를 보여 줘야 하는 사이트 |
| 양쪽 사이드바 | 그리드 모드 | ⭐⭐⭐⭐⭐ | 높은 정보 밀도를 추구하는 기술 중심 스타일 |

## 4. 반응형 레이아웃 동작

Firefly 레이아웃은 화면 크기에 따라 자동 조정되는 반응형 디자인을 갖추고 있습니다.

최적의 읽기 경험을 위해 화면이 좁아지면 레이아웃을 자동 조정합니다.

1. **그리드 열 수 자동 감소**: `columnWidth`와 컨테이너 너비에 따라 열 수를 정하며 화면이 좁을수록 열 수가 줄어듭니다.
2. **목록 모드 → 그리드 모드**: 화면 너비가 380px보다 작으면 카드 콘텐츠의 가독성을 위해 목록 모드가 자동으로 그리드 모드로 바뀝니다.
3. **양쪽 사이드바 → 단일 사이드바**: 화면 너비가 1280px보다 작으면 `tabletSidebar` 설정에 따라 한쪽 사이드바만 표시하고 다른 쪽은 숨기며 글 목차는 플로팅 목차로 바뀝니다.

---

## 5. 자주 묻는 질문

### Q1: 그리드 열 수를 어떻게 조정하나요?

**A**: `columnWidth`로 카드 최소 너비를 설정하면 됩니다. 값이 작을수록 같은 너비에서 열이 많아지고 값이 클수록 열이 줄어듭니다. 브라우저가 사용 가능한 너비에 맞춰 최적의 열 수를 계산합니다.

## 6. 정리

Firefly의 레이아웃 시스템은 간단한 설정만으로 다양한 구성을 구현할 수 있는 높은 자유도를 제공합니다.

콘텐츠 유형과 독자의 기기 선호에 따라 여러 조합을 시험해 블로그에 가장 잘 맞는 형태를 찾아보세요.
