:::tip
[Firefly](https://github.com/CuteLeaf/Firefly)는 `MDX`와 `Markdown` 두 형식의 글을 지원합니다. 두 형식을 함께 사용할 수 있지만 특별히 복잡한 콘텐츠나 요구 사항이 없다면 Markdown 형식만으로도 충분합니다.
:::

## Markdown과 MDX의 차이
- Markdown(MD)은 일반 텍스트로 문서를 작성한 뒤 형식이 적용된 HTML로 변환하는 가벼운 마크업 언어입니다. 간단하고 쓰기 쉬워 문서와 블로그 글 작성에 특히 적합합니다.
- MDX는 Markdown 문서에 JSX 코드를 자연스럽게 삽입할 수 있도록 Markdown 문법을 확장한 형식입니다. React 컴포넌트를 문서에 넣어 더 풍부한 상호 작용과 동적 기능을 구현할 수 있습니다.

| 기능 | Markdown | MDX |
| :--- | :--- | :--- |
| 기본 문법 | 지원(CommonMark) | 지원(CommonMark) |
| HTML 태그 | 지원 | 지원(JSX로 처리) |
| 컴포넌트 가져오기 | 미지원 | 지원(import) |
| 동적 데이터 | 미지원 | 지원(JS 표현식) |
| 스타일 사용자 지정 | 제한적(class/style) | 유연함(className/CSS-in-JS) |

## Firefly 내장 MDX UI 컴포넌트
MDX 글에서 바로 사용할 수 있는 Firefly 내장 MDX UI 컴포넌트를 소개합니다.

### 탭 그룹: `TabGroup`
전환 가능한 탭을 만들어 여러 언어나 버전의 코드를 보여 줄 때 편리합니다.
````mdx
<TabGroup labels={["test.js", "test.py"]} client:load>
  ```js
  console.log(1)
  ```

  ```py
  print("hello world")
  ```
</TabGroup>
````

### 타임라인: `Timeline` / `TimelineItem`

| 속성 | 필수 | 설명 |
| :--- | :--- | :--- |
| `date` | 아니요 | "2024-03-10"과 같은 시간 레이블 |
| `title` | 아니요 | 항목 제목 |
| `type` | 아니요 | 노드 색상. default는 테마 색상이며 나머지는 알림 상자 색상표에 대응합니다(tip / note / important / warning / caution). |
| `icon` | 아니요 | 원 안에 표시할 내장 아이콘 이름: star / rocket / git / flag / book / heart / zap / bug / tag / calendar / code / edit |
| 본문 | 아니요 | `<TimelineItem>` 태그 안의 내용. Markdown을 지원합니다. |

```mdx
<Timeline>
  <TimelineItem date="2026-08-16" title="새 버전 출시" icon="rocket">
    다음 변경 사항을 담은 새 버전을 출시했습니다.

    - 타임라인 컴포넌트 추가
    - 다크 테마 개선

    본문에서 **Markdown**을 사용할 수 있습니다.
  </TimelineItem>
  <TimelineItem date="2025-11-02" title="사이트 공개" type="tip" icon="flag">
    제 블로그에 오신 것을 환영합니다.
  </TimelineItem>
  <TimelineItem date="2025-06-15" title="프로젝트 시작" type="note">
    Firefly 테마 기획을 시작했습니다.
  </TimelineItem>
</Timeline>
```

### 단계 목록: `Steps` / `StepItem`

번호가 있는 단계 목록으로 튜토리얼이나 배포 절차에 적합합니다. 번호가 자동 생성되므로 직접 전달할 필요가 없습니다.

| 속성 | 필수 | 설명 |
| :--- | :--- | :--- |
| `title` | 아니요 | 단계 제목 |
| `type` | 아니요 | 번호 원의 색상. default는 테마 색상이며 나머지는 알림 상자 색상표에 대응합니다(tip / note / important / warning / caution). |
| `icon` | 아니요 | 내장 아이콘 이름. 지정하면 숫자 대신 아이콘을 표시합니다(star / rocket / git / flag / book / heart / zap / bug / tag / calendar / code / edit). |
| 본문 | 아니요 | `<StepItem>` 태그 안의 내용. Markdown을 지원합니다. |

```mdx
<Steps>
  <StepItem title="의존성 설치">
    `pnpm install`을 실행합니다.
  </StepItem>
  <StepItem title="개발 서버 시작" type="tip" icon="rocket">
    `pnpm dev`를 실행하고 `localhost:4321`을 엽니다.
  </StepItem>
  <StepItem title="글 작성">
    `src/content/posts/`에 새 `.mdx` 글을 만듭니다.
  </StepItem>
</Steps>
```
