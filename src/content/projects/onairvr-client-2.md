## 프로젝트와 담당 역할

[onAirVR](https://www.onairvr.io/)은 PC에서 렌더링한 VR 콘텐츠를 모바일 HMD로 무선 전송하고, HMD의 자세와 입력을 PC로 돌려보내는 클릭트의 스트리밍 솔루션이다. 스튜디오 클라이언트와 세션별 카메라 리그를 구현한 데 이어, 2017년 1월부터 5월까지 진행한 Client 2.0 개발에 참여했다.

## 담당 업무

- 기존 onAirVR Client의 UI 개선
- 최신 OVR API 변경에 대응
- Daydream 지원을 위한 GoogleVR API 연동
- 기존 사내 콘텐츠 3개를 데모용 콘텐츠로 제작
